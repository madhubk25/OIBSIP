Data Analytics – Level 1 Task 1

Exploratory Data Analysis on Retail Sales Data

Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a retail sales dataset to identify sales trends, customer purchasing patterns, product category performance, and other useful business insights.

Objectives

- Understand the structure and characteristics of the retail sales data.
- Clean and prepare the dataset for analysis.
- Analyze sales trends over time.
- Study sales performance across product categories.
- Analyze customer demographics and purchasing behavior.
- Identify relationships between numerical variables using correlation analysis.
- Generate meaningful business insights and recommendations.

Dataset

The dataset contains 1,000 retail transactions with the following information:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

Analysis Performed

The analysis includes:

- Data loading and inspection
- Data quality and missing-value checking
- Descriptive statistics
- Gender-wise sales analysis
- Product category analysis
- Monthly sales trend analysis
- Age-group sales analysis
- Correlation analysis
- Identification of high-value transactions
- Business recommendations

Key Findings

- Total sales generated: ₹4,56,000
- Average sales per transaction: ₹456
- Electronics generated the highest total sales among the product categories.
- Clothing recorded the highest quantity sold.
- Female customers contributed slightly higher overall sales than male customers.
- The 46–55 age group generated the highest sales.
- Price per Unit showed a strong positive relationship with Total Amount.

Files

- "Retail_Sales_EDA.ipynb" – Jupyter Notebook containing the complete analysis.
- "retail_sales.xlsx.csv" – Retail sales dataset used for the analysis.

Conclusion

The analysis demonstrates how Exploratory Data Analysis can be used to transform raw retail transaction data into meaningful business insights. The findings can support better decisions related to product planning, customer targeting, marketing strategies, and sales performance.
